# Underwater Jellyfish Detection and Classification using SBNN-HSOA

A deep learning framework for **underwater jellyfish image classification** using **RSCQKF-based image enhancement**, **Spatial Bayesian Neural Network (SBNN)**, and **Humboldt Squid Optimization Algorithm (HSOA)**.

### 🔹 Key Capabilities

* 🌊 Underwater image enhancement using RSCQKF
* 🧠 Spatial Bayesian Neural Network for classification
* 🦑 HSOA-based parameter optimization
* 📊 11-class underwater image classification
* 📈 Accuracy: **98.75%**
* 🎯 Macro-F1: **98.14%**
* 📁 Dataset: **3,168 labeled images**

The framework is designed to improve reliable jellyfish recognition under challenging underwater conditions.
